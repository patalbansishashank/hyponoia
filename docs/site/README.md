# Landing page — not currently deployed

[← docs](../README.md)

`index.html`, `sitemap.xml` and `robots.txt` were a GitHub Pages site served at
`patalbansishashank.github.io/hyponoia`. **It is not deployed.** The workflow
that published it was removed, because Pages on a private repository needs a
paid plan and the job failed on every push to main.

They are kept here, in their own directory, so that they are obviously a
separate artifact rather than documentation. If the repository goes public and
Pages is re-enabled, this is the material to start from — but read it first:
it is a marketing page written for an earlier state of the project and it
duplicates claims that live in the README and in [`../llms.txt`](../llms.txt).

`scripts/check-docs-claims.sh` covers the counts in `index.html`, so at least
those cannot drift silently while it sits here.
